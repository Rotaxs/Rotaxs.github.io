Windows11 操作系统

认识主流的操作系统

操作系统本质上是一个软件，只不过其与计算机硬件进行“通讯”

  • Windows：目前，Windows 操作系统由微软公司（Microsoft Coporation）开发，因此 Windows 系统也集成了微软公司的生态，如办公软件有 Microsoft Office，Outlook 等，游戏有 Xbox，人工智能有 Copilot，浏览器有 Microsoft Edge。因此 Windows 操作系统几乎统治了全球的个人电脑市场

  • Mac OS：Max OS 由苹果公司开发，其在生态安全性和稳定性上具有优势，但在软件兼容性和硬件选择上有一定限制

  • Linux：Linux 严格意义上不能被称为一个操作系统，而是一个操作系统内核，基于该内核（开源），市面上有了很多 Linux 发行版（操作系统），如国人研发的 Deepin 就是基于 Linux 开发的。此外较为流行的发行版还有 Ubuntu，CentOS，ArchLinux，Fedora 等。Linux 系统凭借其开源高度自定义的特点，在服务器，嵌入式等领域有非常突出的应用

桌面和文件夹

C 盘一般被成为系统盘，因此，在 C 盘中会有一些特殊的文件夹，我们主要来认识下图框出来的四个

  • 首先是Program File和Program Files(x86)文件夹，这两个文件夹都用于存放应用程序，区别是（在目前主流的 64 位操作系统下）前者用于存放 64 位的应用程序，而后者用于存放 32 位的应用程序

  • Windows文件夹是 Windows 操作系统的核心文件夹，其中比较常用的是Fonts文件夹，该文件夹用于存放 Windows 可用的字体，也可以下载第三方字体（一般是.ttf文件，双击可安装）

  • 用户文件夹（Users）文件夹用于存放所有用户的数据（Windows 支持多用户），每个用户的数据相互独立（用以用户名命名的文件夹区分），其中，可能有的文件夹如下

  • .config文件夹

    • 存放一些软件的个人配置文件

  • 桌面（Desktop）文件夹

    • 电脑桌面
    • 即电脑桌面是个特殊的文件夹

  • AppData文件夹

    • 这是一个隐藏文件夹，需勾选显示隐藏文件夹（后文会介绍）
    • 该文件夹用于存放应用数据或配置文件，其中的Local，Roaming，LocalLow表示不同类型的应用数据

文件系统

文件系统是操作系统用于管理文件的“标准”，不同操作系统的文件系统也不同

如今，Windows 主要使用NTFS文件系统，不同于老式的FAT32操作系统，NTFS不再限制单个文件大小为 4GB。且其具有日志功能，可以记录电脑的操作，即使电脑断电，也能更好的恢复电脑数据

什么时候会用到文件系统？

文件系统看似与普通用户关系不大，实际上，当我们格式化（清空硬盘数据并改变改变文件系统格式） U 盘或硬盘时，系统会让我们选择一个文件系统。这时如果选择不当，可能会影响硬盘使用体验

认识文件路径

为方便管理文件，每个文件夹和文件都有一个自己的“地址”

在 Windows 系统中，路径从盘符开始，基本的路径格式如下

C:\文件夹1\文件夹2\文件1.txt

这表明在 C 盘下有一个文件夹叫文件夹1，文件夹1下有个文件夹叫文件夹2，文件夹2下有个文件叫文件 1

一般的，文件夹（Folder）也被称为目录（Directory）

由于文件夹的唯一性，因此在同一目录下，不能存在同名文件或同名文件夹（文件和文件夹也不可以同名）

任务栏

一般来说，任务栏从左到右依次是开始菜单，（windows 搜索），应用程序区，系统托盘区

实际上，在任务栏的最右边有一个隐藏的按钮，点击可快速切换回桌面

此外，右击任务栏空白处，可以打开任务栏设置

将相应的应用或快捷方式拖到任务栏，可以将其添加到任务栏

文件

这里我们需要搞清楚软件和文件的关系

例如一个.png图片文件，我们在电脑上直接双击就可以打开了

这看起来很自然，但是实际上，真正的过程是系统调用了相应的软件（如图片查看器），然后软件解析该文件

这时有人可能会问：我电脑上也没装图片查看器啊

其实，大部分 Windows 电脑上都自带了一个叫照片的软件（可以在开始菜单搜索搜到），这个软件可以解析.png格式的文件

同样的，如果电脑上没装Microsoft Office或WPS Office等办公软件，我们也无法打开.docx，.pptx，.xlsx等文件，并且这些文件也不会显示相应的图标，这是因为只有在安装相应的软件时，软件会通过修改注册表（后面会有介绍）为这些文件添加图标

对于程序员来说，一个.c文件，如果在电脑上没有装编译器或 IDE，那它也就是个普通的文本文件，与.txt文件（文本文件）也就只有扩展名不同的区别了

当电脑上有多个应用可以打开同一个文件时，可以右键该文件，在更多中找到打开方式，直接选择相应的应用打开；或者点击选择其他应用程序，在弹出的窗口中选择相应的程序后点击始终，从而修改这类文件的默认打开方式

这里再介绍一种特殊的文件——压缩文件

这类文件通常以.zip，.rar，.7z结尾，不同的扩展名表示不同的压缩算法，微软只为我们提供了处理.zip的软件，而且确实不太好用（可以用第三方软件，后面会介绍）

压缩文件可以将多个文件夹和文件合并为一个文件，便于传输分享

综上，没有软件，那么文件也没有用

快捷方式

快捷方式可以理解为一个链接，指向相应的文件或网址

通常我们安装软件后出现在桌面的就是快捷方式，其特点是图标的左下角有一个指向右上的箭头

因此，删除快捷方式并不等于卸载软件，具体的卸载软件的方式后面会介绍

我们也可以创建快捷方式，一般有两种方式

  1. 右键相应的文件（软件）或文件夹，在更多中找到并点击创建快捷方式

  2. 在空白处右键，点击新建，选择快捷方式，会弹出一个窗口

接着可以在输入框中输入文件（夹）路径或网址

tips：由于快捷方式只是一个链接，因此，修改快捷方式的文件名或是图标（右键快捷方式，选择更多-属性-快捷方式-更改图标）都不会对原文件（夹）有影响顺带一提，快捷方式其实是有扩展名的，扩展名为 .ink

系统应用

系统应用分为两种

  • 一种是传统的应用程序，一般在 C:\Windows\System32 目录下，如任务管理器等

  • 另一种是自从 Win10 发布后，微软新推出的应用程序，即 UWP （Universal Windows Platform），这种应用最大的特点是通过微软应用商店（Microsoft Store）下载，存储位置一般在 C:\Program Files\WindowsApps，如计算器等

了解可执行文件

传统的应用一般是可执行文件（以.exe结尾）

此外，在网络上可以下载到的可执行文件还有.msi（安装包文件，有时候.exe文件也可以作为安装包），.bat/.cmd（批处理文件，一般用于修改系统设置，文件批量处理）

需要注意的是，在 Windows 11 后运行可执行文件时会弹出一个窗口询问是否允许对设备进行修改，因为有的可执行文件可能会携带（或本身就是）病毒等非法程序，因此切忌运行来路不明的可执行文件

动态链接库文件

我们常常会在应用的安装目录下看到许多.dll文件，这些就是动态链接库文件，其包含了一套给可执行程序调用的函数和数据，且可以共享给多个程序调用

可以理解为一个.dll文件实现了一个或多个基础功能，可执行程序通过调用这些基础功能从而实现更加复杂的功能

接下来介绍一些比较重要的系统应用

文件资源管理器

双击桌面上的此电脑（新系统可能需要设置），可以打开文件资源管理器（explorer）

也可通过快捷键Win+E打开

这里强烈建议打开文件扩展名，如下

通过左键选中并右击文件夹，可以选择将文件夹固定到快速访问栏

通过上方的地址栏可以快速定位到文件夹

任务管理器

右击任务栏空白处，可以打开任务管理器（task manager 简称 taskmgr）

也可以通过快捷键Ctrl+Shift+Esc或Ctrl+Alt+Del打开任务管理器

在任务管理器中，我们可以看到目前电脑上的进程，以及各进程的 CPU 和内存损耗

右击进程，可以选择结束进程以减少电脑损耗（如在电脑卡顿或应用无响应时可结束相应进程）

注册表

注册表（Registry Editor，简写为 Regedit）是一个巨大的、分层级的数据库，用于存储 Windows 操作系统、所有硬件设备、以及几乎所有已安装应用程序的配置信息和设置

Windows 中有许多配置信息，如桌面壁纸，右键菜单的项 等，当然不能把他们放在内存或缓存里，但是直接放在硬盘中也不安全（可能会被随意修改）

因此，微软将这些数据放在一些文件中（当电脑运行时，这些文件和对应的文件夹会被锁定，不允许用户访问），并且提供了注册表这个接口 给用户访问

要想打开注册表，可以直接在开始菜单搜索注册表，也可以按下Win+R打开运行窗口，然后输入regedit，并按下回车

有关注册表的更多内容，这里就不展开了

截图工具

看了那么多理论，再来了解一点实用的

相信很多人在电脑上截图都是用的微信或 QQ 的截图工具，实际上，Windows 自带了一个截图工具

虽然功能上比不上前者，但其胜在简洁快捷，通过快捷键Win+Shift+S可以打开截图工具

然后在窗口上方的选项中可以选择截屏或录屏，选择后选定要截图的区域就可以了

截完的图会保存在剪切板中，可以直接用Ctrl+V粘贴在聊天对话框，或在用户目录下的图片文件夹中找到相应的截图文件

如果是录屏，则结束后的文件会保存在用户目录下的视频文件夹中

第三方应用

如何下载第三方应用

下载应用主要有下面三种渠道

  • 浏览器搜索

  • 微软应用商店

  • 品牌电脑自带的应用商店

对于第一种方式，由于 Windows 的“开放包容”，网络上有很多应用程序携带病毒或广告

而对于后两者，我们常常无法保证软件是最新的版本，且有些软件无法在上面找到

我们尝试换位思考，一个开发者，写了一个自己的软件，他会把它放在哪里？答案是 官网

我始终坚持，软件应该去官网或开发者指定的渠道下载

是否是官网也需要辨别，有些软件会伪装成其他软件的官网（实在恶心），一般可以看网站的域名辨别是否是官网

到这里，又会遇到一些问题

  • 无法进入官网

  • 官方正版要付费

有些国外的软件服务器在海外，（由于种种原因）国内常常无法访问这些网站，这时就需要“科学上网”（无法多说）

而对于付费软件，能支持的尽量支持，如果价格实在不太合理，可以去相关论坛或视频网站找大佬分享的破解版（不推荐）

解决了下载软件的问题，就可以了解电脑上的一些常用的软件了

微信/QQ

在 微信官网 和 QQ 官网 ，我们都能看到很多下载选项，一般选择 Windows 64 位 就可以了

吐槽一下：微信和 QQ 对国人影响太大了

这虽然便利了我们的使用，但是也应该让我们有一些思考

比如，当我们在微信中点开一个链接，为什么我们能够进入这个网站，看到里面的内容？

再比如，在手机微信中（电脑微信没这个功能）点开一个文档，可以在微信内部直接打开？

可以说，微信/QQ 就是两个“缝合怪”，里面除了聊天，还内置了图片查看器，浏览器，小程序，文件管理和传输工具等功能

但实际上，微信的内置浏览器和文档阅读器都极其简陋，有时候我们无法获得想要的效果

因此，当有人给我们发来一个链接或文件时，（在非临时情况下）我们尽量用专门的软件打开

解压缩软件

解压缩软件推荐两个，分别是 7-zip 和 Bandzip，这两款软件能识别的压缩文件格式较多，功能强大，区别是前者 UI 较为简陋，后者免费版有广告（影响不大）

办公软件

国内的 WPS 还算不错，如果追求更强大的功能，也可以用微软的 Microsoft 365（订阅版），或最新的 Office 2024（买断制） ，但是有点贵（有的笔记本会赠送 Office）

如果用的微软的 Office，那么不会有 PDF 阅读器（WPS 会自带一个 PDF 阅读器），这时可以考虑 PDFgear

卸载软件

电脑上卸载软件有以下几种方式

  1. 使用软件自带的卸载程序（推荐）

  • 很多软件在安装目录下会有一个 Uninstall.exe 可执行程序，双击运行即可卸载该软件

  • 缺点是软件的残留数据不一定被清除

  1. 控制面板中的卸载程序（不推荐）

  • 开始菜单搜索控制面板，点击卸载程序，找到相应的软件双击卸载

  • 本质是运行软件安装目录下的 Uninstall.exe

  1. 第三方软件卸载（强烈推荐）

  • 使用正确的第三方软件不但能卸载软件本体，还能清除残存数据

这里推荐的软件是 HiBit Uninstaller

进入官网我们可以看到软件提供了两个版本

  • Installable Version：即提供一个安装包，需要安装后使用

  • Protable Version：也就是常说的绿色版，下载后解压即可直接使用

这里按自己需求选择就行，不知道怎么选的话选 Installable Version 就行

驱动

前面我们了解到，操作系统是直接和硬件打交道的，但是不同的硬件的制造厂商不同，操作系统如何知道调用这些硬件呢

这就需要驱动程序（Device Driver）了，驱动程序由硬件厂商编写，负责将操作系统的命令翻译成硬件能理解和执行的指令

常见的驱动有打印机驱动，显卡驱动，声卡驱动，USB 驱动

因此当你发现某个硬件突然不工作了，除了考虑是否是硬件损坏，应该优先考虑是不是驱动除了问题

也许你会说装电脑这么久从来都没装过驱动，其实是 Windows 系统会自动安装相应的驱动（打印机驱动一般要手动安装），代价是驱动可能不与硬件完全匹配，导致硬件无法发挥最大效能

开始菜单搜索并打开设备管理器，可以看到当前计算机的硬件，对于每一个硬件，都能找到对应的驱动程序

当某个硬件图标旁显示了黄色感叹号时，说明该硬件不能正常工作，需要下载相应的驱动

可以选择双击硬件图标，选择驱动程序-更新驱动程序-自动搜索驱动程序

如果没有搜索到相应的驱动，则需要去硬件的官网下载相应驱动，然后点击浏览我的电脑以查找对应驱动进行手动安装

tips：安装完驱动后，驱动文件就可以删除了

浏览器

浏览器可以说是电脑上最常用的一个软件了

但是，浏览器除了上网外，还有很多实用的配置

在了解浏览器之前，我们先来认识一下搜索引擎

搜索引擎

搜索引擎（Search Engine）是一种特殊的网站或软件服务。它的核心工作是收集、整理和索引互联网上数以万亿计的网页内容，并在你提出问题时，快速为你找到最相关的信息

搜索引擎利用爬虫技术，不断在网络上爬取数据并存入相应的数据库，当用户输入信息时，搜索引擎就会在数据库中检索相关信息，进行排序后展示给用户

目前主流的搜索引擎如下

  • Google：由谷歌公司开发，是全球最大的搜索引擎，检索能力强，国内网络无法访问

  • Bing：由微软公司开发，是Microsoft Edge浏览器的默认搜索引擎

  • 百度：百度公司开发，国内主流，百度广告那么多，不理解为什么要用百度

正确使用搜索引擎能帮助我们提高检索信息的效率，以下是一些搜索引擎的“高级”用法

  • 精确搜索：""

    • 强制搜索引擎只返回完全相同、顺序不变的短语的网页
    • 如搜索 "苹果手机"，那么搜索引擎就会返回包含苹果手机完整短语的条目

  • 排除关键字：-

    • 排除不需要的内容
    • 如搜索 苹果 - 手机，那么结果中就不会出现苹果手机相关内容，而返回苹果的相关条目

  • 站内搜索：site:

    • 在特定网站搜索
    • 如搜索 二分查找 site:www.zhihu.com，那么结果全是知乎中关于二分查找的文章

  • 按文件类型查找：filetype:

    • 查找文件
    • 如搜索 数据结构 filetype:pdf 那么返回的结果就都是 pdf 文件

浏览器基本元素

现代浏览器的基本元素如下

  • 标签页

    • 一个标签页就是一个页面
    • 主页：一种特殊但又不那么特殊的标签页，用来作为浏览器的初始页面，可放些常用网址

  • 地址栏

    • 网址输入在这里
    • 地址栏一般也可以当作搜索栏来用（调用的搜索引擎可以在浏览器设置中进行设置）

  • 搜索栏

    • 调用搜索引擎进行搜索（Edge 浏览器默认主页的搜索引擎是 Bing）
    • 不能输入网址

  • 收藏夹栏/书签栏

    • 存放一些常用网站

  • 扩展

    • 后面会介绍

浏览器内核

当我们在浏览器地址栏输入对应的地址时，对方服务器就会发送信息到我们的电脑上，而要想渲染这些信息，就需要浏览器内核

浏览器内核由渲染引擎和JavaScript 引擎组成，前者决定网页的样式，后者决定网页的功能

主流的浏览器内核如下

  • Chromium 内核

    • 谷歌公司开发
    • 代表浏览器：Chrome，Microsoft Edge，Opera

  • Gecko 内核

    • 代表浏览器：Mozilla Firefox

  • WebKit 内核

    • 代表浏览器：Apple Safari

由于不同的内核对前端代码的“翻译”不同，因此会出现同一个网页在不同内核的浏览器上的表现效果不同的情况（比如 Chrome 的扩展可以在 Edge 上使用，但不能在 Firefox 上使用）

认识命令提示符

命令提示符（Command Prompt，简写为 cmd）

通过Win+R呼出运行窗口，输入cmd即可打开

也可以在开始菜单搜索命令提示符打开

在命令提示符中可以运行一些简单的指令，一下是一些常用的命令和效果

注意到在所有的文件和文件夹最上面还有一个.吗？在计算机中，我们用.表示当前目录，用..表示上一级目录

cmd 对大小写并不敏感，即 Dir 与 dir 表示同一个意思

cmd 也有运行窗口的功能，即输入变量名可以访问变量值，因此，接下来我们来介绍一下环境变量

环境变量

环境变量相当于计算机全局的变量，通过设置环境变量，我们可以在计算机的其他地方访问到某个特定文件或文件夹

通过Win+R呼出运行窗口，输入taskmgr会发现系统打开了任务管理器

实际上，任务管理器作为一个软件（文件名为taskmgr.exe），其保存在文件夹C:\Windows\System32中，Windows 系统通过设置该目录为环境变量，将该目录下中所有的文件添加到了环境变量中，使得这些文件可以在全局被访问（如果是.exe文件，在访问时可以省略扩展名）

同样的，如果在运行窗口或资源管理器的路径栏中输入%windir%，资源管理器就会自动跳转到C:\Windows路径下，因为 Windows 默认将 windir 作为该路径的变量名，通过 %变量名% 就可以直接访问该路径

配置环境变量

在桌面上右键此电脑（没有的需按前文个性化设置条目进行配置），点击属性，往下翻可以找到高级系统设置，然后点击环境变量

在弹出的窗口中可以看到两栏，用户变量和系统变量

Windows 是一个多用户系统，即一个电脑可以有多个用户不同用户有不同的电脑桌面，文件等，权限也可以不同

我们一般不需要对此进行区分，只需要操作用户变量就行

首先需要关注Path变量，双击该变量，在弹出的窗口中我们可以看到很多路径，这里存放的就是文件（软件）的环境变量（注意是添加该文件所在的目录）

比如在C:\Program Files (x86)\mingw64\bin目录下有一个gcc.exe文件，我想把该文件添加到环境变量，只需要点开Path，然后点击新建，复制该路径就可以了

接下来在cmd就可以使用该程序了

如果要添加文件夹变量，只需要在用户变量新建并输入文件夹路径即可

注：配置完环境变量后要点击确定直至关闭所有窗口（设置窗口除外）

  • 大小写切换/输入字符切换：Shift+相应按键

特殊按键

  • Insert键（ins）

    • 部分编辑器支持，可以把光标变成方框，当输入时会覆盖后面的字符

    • 制表符的映射

    • 部分软件用于终止会话

格式化 U 盘

当 U 盘损坏无法打开时，有时可以通过格式化 U 盘“修复”（当然 U 盘中的数据也会被清空），方法如下

将 U 盘插入电脑相应的接口

按下 Win + X，选择磁盘管理

找到 U 盘对应的分区（可根据 U 盘容量大小判断），右键该分区，选择格式化

卷标即 U 盘名称，可自定义，文件系统 选择 NTFS，其他保持不变，然后点击确定即可开始格式化 U 盘了

曲线积分

第一类曲线积分

考虑这样一个问题，在一个密度场 ρ=f(x,y)\rho = f(x, y)ρ=f(x,y) 中有一根绳子，绳子的形状不规则，但是可以用函数如 L(x,y)=0L(x, y) = 0L(x,y)=0 表示，现在要求这根绳子的质量，应该如何思考

考虑高中物理中常用的微元法，将绳子划分为无数的小段，每一段的长度为 ds\mathrm{d}sds，那么该点处的质量为 f(x,y)dsf(x, y)\mathrm{d}sf(x,y)ds，故而绳子的总质量为

∑f(x,y)ds\sum f(x, y)\mathrm{d}s ∑f(x,y)ds

要想让每一段的绳长尽可能地接近 0，我们可以取所有段中最长的那段的长度为 λ\lambdaλ，然后取极限，得到

lim⁡λ→0∑f(x,y)ds\lim_{\lambda\to 0}\sum f(x, y)\mathrm{d}s λ→0lim​∑f(x,y)ds

这就是第一类曲线积分的“原本面貌”，我们引入一个符号记这个表达式，即

∫Lf(x,y)ds=lim⁡λ→0∑f(x,y)ds\int_{L}f(x, y)\mathrm{d}s = \lim_{\lambda\to 0}\sum f(x, y)\mathrm{d}s ∫L​f(x,y)ds=λ→0lim​∑f(x,y)ds

第二类曲线积分

在第一类曲线积分中，被积函数和 ds\mathrm{d}sds 都是标量，如果将标量场换成向量场 A⃗(x,y)\vec{A}(x, y)A(x,y)，ds\mathrm{d}sds 也换成 dr⃗\mathrm{d}\vec{r}dr，就得到第二类曲线积分

∫LA⃗(x,y)⋅dr⃗=lim⁡∑A⃗(x,y)⋅dr⃗\int_{L}\vec{A}(x, y)\cdot\mathrm{d}\vec{r} = \lim\sum \vec{A}(x, y)\cdot\mathrm{d}\vec{r} ∫L​A(x,y)⋅dr=lim∑A(x,y)⋅dr

若将点积形式展开（记 A⃗(x,y)=(P,Q)\vec{A}(x, y) = (P, Q)A(x,y)=(P,Q)），那么就能得到

∫LA⃗(x,y)⋅dr⃗=∫LP(x,y)dx+∫LQ(x,y)dy\int_{L}\vec{A}(x, y)\cdot\mathrm{d}\vec{r} = \int_{L}P(x, y)\mathrm{d}x + \int_{L}Q(x, y)\mathrm{d}y ∫L​A(x,y)⋅dr=∫L​P(x,y)dx+∫L​Q(x,y)dy

为了书写方便，上式还可以忽略一个积分符号写成

∫LA⃗(x,y)⋅dr⃗=∫LP(x,y)dx+Q(x,y)dy\int_{L}\vec{A}(x, y)\cdot\mathrm{d}\vec{r} = \int_{L}P(x, y)\mathrm{d}x + Q(x, y)\mathrm{d}y ∫L​A(x,y)⋅dr=∫L​P(x,y)dx+Q(x,y)dy

显然，这里的 dx\mathrm{d}xdx 和 dy\mathrm{d}ydy 其实是 ds\mathrm{d}sds 在坐标轴上的分量

并且由于积分变量 dr⃗\mathrm{d}\vec{r}dr 是矢量，因此第二类曲线积分需要考虑方向，也就是说

∫ABA⃗(x,y)⋅dr⃗=−∫BAA⃗(x,y)⋅dr⃗\int_{\textcolor{red}{AB}}\vec{A}(x, y)\cdot\mathrm{d}\vec{r} = -\int_{\textcolor{red}{BA}}\vec{A}(x, y)\cdot\mathrm{d}\vec{r} ∫AB​A(x,y)⋅dr=−∫BA​A(x,y)⋅dr

将曲线积分转化为定积分

先看第一类曲线积分，由于积分变量是 ds\mathrm{d}sds，我们无法直接计算，因此我们可以先考虑转化积分变量，弧微元的表达式为

ds=(dx)2+(dy)2\mathrm{d}s = \sqrt{(\mathrm{d}x)^2 + (\mathrm{d}y)^2} ds=(dx)2+(dy)2​

进一步化简得到

ds=1+(dydx)2dx=1+y′2dx\mathrm{d}s = \sqrt{1 + \left(\frac{\mathrm{d}y}{\mathrm{d}x}\right)^2}\mathrm{d}x = \sqrt{1 + y'^2}\mathrm{d}x ds=1+(dxdy​)2​dx=1+y′2​dx

这样一来就能够将积分变量转化为 xxx，然后将被积函数中所有的 yyy 通过曲线的函数表达式换成 xxx，就可以转化为定积分计算了

此外，还可以引入参数方程

其中，t1t_1t1​ 和 t2t_2t2​ 是曲线的起点参量和终点参量

第一类曲线积分和第二类曲线积分的关系

第二类曲线积分相较于第一类曲线积分就是向量和标量的区别，实际上

∫LA⃗⋅dr⃗=∫LA⃗⋅τ⃗ds\int_{L}\vec{A}\cdot\mathrm{d}\vec{r} = \int_{L}\vec{A}\cdot\vec{\tau}\mathrm{d}s ∫L​A⋅dr=∫L​A⋅τds

平面曲线积分与路径无关的条件

我们观察

∫LPdx+Qdy\int_{L}P\mathrm{d}x + Q\mathrm{d}y ∫L​Pdx+Qdy

不难发现这里的 Pdx+QdyP\mathrm{d}x + Q\mathrm{d}yPdx+Qdy 与全微分及其相似

如果 z=f(x,y)z = f(x, y)z=f(x,y)，且 P=∂f∂xP = \frac{\partial f}{\partial x}P=∂x∂f​，Q=∂f∂yQ = \frac{\partial f}{\partial y}Q=∂y∂f​，那么

dz=Pdx+Qdy\mathrm{d}z = P\mathrm{d}x + Q\mathrm{d}y dz=Pdx+Qdy

需要注意的是，不是所有的 Pdx+QdyP\mathrm{d}x + Q\mathrm{d}yPdx+Qdy 都是恰当微分，即不一定所有的 Pdx+QdyP\mathrm{d}x + Q\mathrm{d}yPdx+Qdy 都能收成 dz\mathrm{d}zdz 的形式

从而有

∫LPdx+Qdy=∫z1z2dz\int_{L}P\mathrm{d}x + Q\mathrm{d}y = \int_{z_1}^{z_2}\mathrm{d}z ∫L​Pdx+Qdy=∫z1​z2​​dz

这时我们发现这个曲线积分的结果只与初末位置的 zzz 坐标有关，即曲线积分与路径无关

接下来考虑恰当微分的充要条件

假定 Pdx+QdyP\mathrm{d}x + Q\mathrm{d}yPdx+Qdy 是恰当微分，那么

∂P∂y=∂2f∂x∂y=∂Q∂x\frac{\partial P}{\partial y} = \frac{\partial^2 f}{\partial x\partial y} = \frac{\partial Q}{\partial x} ∂y∂P​=∂x∂y∂2f​=∂x∂Q​

即 ∂P∂y=∂Q∂x\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}∂y∂P​=∂x∂Q​ 是恰当微分的一个必要条件

接下来证明充分性

若 ∂P∂y=∂Q∂x\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}∂y∂P​=∂x∂Q​，那么假设 P(x,y)=∂f∂xP(x, y) = \frac{\partial f}{\partial x}P(x,y)=∂x∂f​，则

f(x,y)=∫x0xP(x,y)dx+ϕ(y)f(x, y) = \int_{x_0}^{x}P(x, y)\mathrm{d}x + \phi(y) f(x,y)=∫x0​x​P(x,y)dx+ϕ(y)

则

∂f∂y=∂∂y[∫x0xP(x,y)dx+ϕ(y)]=∫x0x∂P∂ydx+ϕ′(y)=∫x0x∂Q∂xdx+ϕ′(y)=Q(x,y)−Q(x0,y)+ϕ′(y)\begin{align} \frac{\partial f}{\partial y} & = \frac{\partial }{\partial y}\left[\int_{x_0}^{x}P(x, y)\mathrm{d}x + \phi(y)\right]\\ & = \int_{x_0}^{x} \frac{\partial P}{\partial y}\mathrm{d}x + \phi'(y)\\ & = \int_{x_0}^{x} \frac{\partial Q}{\partial x}\mathrm{d}x + \phi'(y)\\ & = Q(x, y) - Q(x_0, y) + \phi'(y) \end{align} ∂y∂f​​=∂y∂​[∫x0​x​P(x,y)dx+ϕ(y)]=∫x0​x​∂y∂P​dx+ϕ′(y)=∫x0​x​∂x∂Q​dx+ϕ′(y)=Q(x,y)−Q(x0​,y)+ϕ′(y)​​

令 Q(x,y)=Q(x,y)−Q(x0,y)+ϕ′(y)Q(x, y) = Q(x, y) - Q(x_0, y) + \phi'(y)Q(x,y)=Q(x,y)−Q(x0​,y)+ϕ′(y)，则 ϕ′(y)=Q(x0,y)\phi'(y) = Q(x_0, y)ϕ′(y)=Q(x0​,y)，从而

ϕ(y)=∫y0yQ(x0,y)dy+C\phi(y) = \int_{y_0}^{y}Q(x_0, y)\mathrm{d}y + C ϕ(y)=∫y0​y​Q(x0​,y)dy+C

因此存在

f(x,y)=∫x0xP(x,y)dx+∫y0yQ(x0,y)dy+Cf(x,y) = \int_{x_0}^x P(x,y)\mathrm{d}x + \int_{y_0}^y Q(x_0, y)\mathrm{d}y + C f(x,y)=∫x0​x​P(x,y)dx+∫y0​y​Q(x0​,y)dy+C

因此充分性成立，故

∂P∂y=∂Q∂x\textcolor{red}{\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}} ∂y∂P​=∂x∂Q​

是曲线积分与路径无关的充要条件

需要强调的是，上面的结论只适用于单连通区域

实际上，函数 f(x,y)f(x, y)f(x,y) 还可以这样理解

∫(x0,y0)(x,y)dz=f(x,y)=∫(x0,y0)(x,y0)P(x,y)dx+∫(x,y0)(x,y)Q(x0,y)dy+C\int_{(x_0, y_0)}^{(x, y)}\mathrm{d}z = f(x,y) = \int_{(x_0, y_0)}^{(x, y_0)} P(x,y)\mathrm{d}x + \int_{(x, y_0)}^{(x, y)} Q(x_0, y)\mathrm{d}y + C ∫(x0​,y0​)(x,y)​dz=f(x,y)=∫(x0​,y0​)(x,y0​)​P(x,y)dx+∫(x,y0​)(x,y)​Q(x0​,y)dy+C

这可以理解为从 (x0,y0)(x_0, y_0)(x0​,y0​) 到 (x,y)(x, y)(x,y) 的曲线积分还可以写成先从 (x0,y0)(x_0, y_0)(x0​,y0​) 到 (x,y0)(x, y_0)(x,y0​) 再到 (x,y)(x, y)(x,y) 的折线上的曲线积分（与路径无关）

格林公式

格林公式

单连通区域：若 DDD 内任一闭曲线所围的部分都属于 DDD，则称 DDD 为平面单连通区域
复连通区域：若存在 DDD 内某一闭曲线所围的部分不属于 DDD，则称 DDD 为复连通区域通俗地说，单连通区域就是没有“洞”的区域，而复联通区域是有“洞”的区域（包括点洞）

平面区域的方向：对于平面区域 DDD，我们规定 LLL 的正向如下：当观察者沿着 LLL 的这个方向行走时，DDD 在他近处的那一部分总在他的左边

格林公式：设闭区域 DDD 由分段光滑的曲线 LLL 围成，若函数 P(x,y)P(x, y)P(x,y) 及 Q(x,y)Q(x, y)Q(x,y) 在 DDD 上具有一阶连续偏导数，则有

∬D(∂Q∂x−∂P∂y)dxdy=∮LPdx+Qdy\iint_{D}\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)\mathrm{d}x\mathrm{d}y = \oint_{L}P\mathrm{d}x+Q\mathrm{d}y ∬D​(∂x∂Q​−∂y∂P​)dxdy=∮L​Pdx+Qdy

其中 LLL 是 DDD 取正向的曲线边界

接下来先对下面这种简单情况进行证明，设 D={(x,y)∣φ1(x)≤y≤φ2(x),a≤x≤b}D = \{(x, y) \mid \varphi_1(x) \leq y \leq \varphi_2(x), a \leq x \leq b\}D={(x,y)∣φ1​(x)≤y≤φ2​(x),a≤x≤b}

先计算二重积分

∬D∂P∂ydxdy=∫ab[∫φ1(x)φ2(x)∂P∂ydy]dx=∫ab[P(x,φ2(x))−P(x,φ1(x))]dx\iint_{D}\frac{\partial P}{\partial y}\mathrm{d}x\mathrm{d}y = \int_{a}^{b}\left[\int_{\varphi_1(x)}^{\varphi_2(x)}\frac{\partial P}{\partial y}\mathrm{d}y\right]\mathrm{d}x = \int_{a}^{b} [P(x, \varphi_2(x)) - P(x, \varphi_1(x))] \mathrm{d}x ∬D​∂y∂P​dxdy=∫ab​[∫φ1​(x)φ2​(x)​∂y∂P​dy]dx=∫ab​[P(x,φ2​(x))−P(x,φ1​(x))]dx

然后计算曲线积分

∮LPdx=∫PQPdx+∫QRPdx+∫RSPdx+∫SPPdx=∫PQPdx+∫RSPdx=∫ab[P(x,φ1(x))−P(x,φ2(x))]dx\begin{align} \oint_L P\mathrm{d}x & = \int_{PQ} P \mathrm{d}x + \int_{QR} P \mathrm{d}x + \int_{RS} P \mathrm{d}x + \int_{SP} P \mathrm{d}x\\ & = \int_{PQ} P \mathrm{d}x + \int_{RS} P \mathrm{d}x\\ & = \int_{a}^{b} [P(x, \varphi_1(x)) - P(x, \varphi_2(x))]\mathrm{d}x \end{align} ∮L​Pdx​=∫PQ​Pdx+∫QR​Pdx+∫RS​Pdx+∫SP​Pdx=∫PQ​Pdx+∫RS​Pdx=∫ab​[P(x,φ1​(x))−P(x,φ2​(x))]dx​​

因此

∬D∂P∂ydxdy=−∮LPdx\iint_{D}\frac{\partial P}{\partial y}\mathrm{d}x\mathrm{d}y = -\oint_L P\mathrm{d}x ∬D​∂y∂P​dxdy=−∮L​Pdx

同理可得

∬D∂Q∂xdxdy=∮LQdy\iint_{D}\frac{\partial Q}{\partial x}\mathrm{d}x\mathrm{d}y = \oint_L Q\mathrm{d}y ∬D​∂x∂Q​dxdy=∮L​Qdy

因此

∬D(∂Q∂x−∂P∂y)dxdy=∮LPdx+Qdy\iint_{D}\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)\mathrm{d}x\mathrm{d}y = \oint_{L}P\mathrm{d}x+Q\mathrm{d}y ∬D​(∂x∂Q​−∂y∂P​)dxdy=∮L​Pdx+Qdy

如此，若平面区域 DDD 不满足上面的形状，可以将其划分为若干形如 DDD 的形状，然后对每一部分使用上面的公式即可，最后加起来，可以得到格林公式在一般情况下仍然成立

平面曲线积分与路径无关条件的另一证明

前面证明了平面曲线积分与路径无关的充要条件是

∂P∂y=∂Q∂x\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} ∂y∂P​=∂x∂Q​

这个条件的必要性是显然的，接下来我们再用格林公式证明其充分性

首先我们从另一个角度理解路径无关，对于给定两点 AAA 和 BBB，以及两条从 AAA 到 BBB 的路径 L1L_1L1​ 和 L2L_2L2​，那么当

∫L1Pdx+Qdy=∫L2Pdx+Qdy\int_{L_1}P\mathrm{d}x + Q\mathrm{d}y = \int_{L_2}P\mathrm{d}x + Q\mathrm{d}y ∫L1​​Pdx+Qdy=∫L2​​Pdx+Qdy

时，显然曲线积分与路径无关，那么，此时有

∮L1+L2−Pdx+Qdy=∫L1Pdx+Qdy+∫L2−Pdx+Qdy=0\oint_{L_1 + L_2^-}P\mathrm{d}x + Q\mathrm{d}y = \int_{L_1}P\mathrm{d}x + Q\mathrm{d}y + \int_{L_2^-}P\mathrm{d}x + Q\mathrm{d}y = 0 ∮L1​+L2−​​Pdx+Qdy=∫L1​​Pdx+Qdy+∫L2−​​Pdx+Qdy=0

及若经过 AAA BBB 两点的环路的曲线积分为 0，那么曲线积分与路径无关

又因为 ∂P∂y=∂Q∂x\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}∂y∂P​=∂x∂Q​，所以 ∫LPdx+Qdy=0\int_{L}P\mathrm{d}x + Q\mathrm{d}y = 0∫L​Pdx+Qdy=0

因此结论就显然了

曲面积分

第一类曲面积分

和第一类曲线积分类似，第一类曲面积分求的是空间密度场中曲面的质量

具体来说，假设空间中存在一密度场 μ=f(x,y,z)\mu = f(x, y, z)μ=f(x,y,z) 和一曲面 Σ\SigmaΣ，那么我们可以假设曲面上的面积微元 dS\mathrm{d}SdS，那么这个微元的质量为

f(x,y,z)dSf(x, y, z)\mathrm{d}S f(x,y,z)dS

累加并求极限即得曲面积分的定义

∬Σf(x,y,z)dS=lim⁡∑f(x,y,z)dS\iint_{\Sigma} f(x, y, z) \mathrm{d}S = \lim\sum f(x, y, z)\mathrm{d}S ∬Σ​f(x,y,z)dS=lim∑f(x,y,z)dS

第二类曲面积分

同样的，将第一类曲面积分中的标量换成向量即可得到第二类曲面积分

但是在此之前，我们需要先了解面积向量的概念

面积向量的 A⃗\vec{A}A 的定义如下

A⃗=A⋅n⃗\vec{A} = A\cdot \vec{n} A=A⋅n

其中，AAA 是面积的大小，n⃗\vec{n}n 是该平面的单位法向量

如此，便可开始进行替换，将原来的标量场替换成向量场（如速度场），将原来的面积替换为面积向量，因此可以得到第二类曲面积分

∬ΣA⃗⋅dS⃗\iint_{\Sigma}\vec{A}\cdot\mathrm{d}\vec{S} ∬Σ​A⋅dS

同样的，第二类曲面积分也要考虑方向，而方向的基准由 Σ\SigmaΣ 决定，即需要指定曲面 Σ\SigmaΣ 的侧

  • 对于封闭曲面来说，它可以有外侧和内测

  • 对于非封闭的曲面来说，它可以有上/下侧、左/右侧、前/后侧

取不同侧的结果是不一样的，如

∬ΣA⃗⋅dS⃗=−∬Σ−A⃗⋅dS⃗\iint_{\Sigma}\vec{A}\cdot\mathrm{d}\vec{S} = -\iint_{\Sigma^-}\vec{A}\cdot\mathrm{d}\vec{S} ∬Σ​A⋅dS=−∬Σ−​A⋅dS

第一类曲面积分和第二类曲面积分的关系

如果 A⃗=(P,Q,R)\vec{A} = (P, Q, R)A=(P,Q,R)，且法向量与三个坐标轴的夹角分别为 α,β γ\alpha, \beta\, \gammaα,βγ，那么就可以得到

∬ΣA⃗⋅dS⃗=∬ΣPcos⁡α+Qcos⁡β+Rcos⁡γdS\iint_{\Sigma}\vec{A}\cdot\mathrm{d}\vec{S} = \iint_{\Sigma}P\cos\alpha + Q\cos\beta + R\cos\gamma \mathrm{d} S ∬Σ​A⋅dS=∬Σ​Pcosα+Qcosβ+RcosγdS

这其实就是一个第一类曲面积分了

## 软件篇

### Windows11 操作系统

#### 认识主流的操作系统

操作系统本质上是一个软件，只不过其与计算机硬件进行“通讯”

- **Windows**：目前，Windows 操作系统由微软公司（Microsoft Coporation）开发，因此 Windows 系统也集成了微软公司的生态，如办公软件有 Microsoft Office，Outlook 等，游戏有 Xbox，人工智能有 Copilot，浏览器有 Microsoft Edge。因此 Windows 操作系统几乎统治了全球的个人电脑市场

- **Mac OS**：Max OS 由苹果公司开发，其在生态安全性和稳定性上具有优势，但在软件兼容性和硬件选择上有一定限制

- **Linux**：Linux 严格意义上不能被称为一个操作系统，而是一个操作系统内核，基于该内核（开源），市面上有了很多 Linux 发行版（操作系统），如国人研发的 Deepin 就是基于 Linux 开发的。此外较为流行的发行版还有 Ubuntu，CentOS，ArchLinux，Fedora 等。Linux 系统凭借其**开源高度自定义**的特点，在服务器，嵌入式等领域有非常突出的应用

#### 桌面和文件夹

C 盘一般被成为系统盘，因此，在 C 盘中会有一些特殊的文件夹，我们主要来认识下图框出来的四个

{% asset_img 文件夹.png 图：文件夹 %}

- 首先是`Program File`和`Program Files(x86)`文件夹，这两个文件夹都用于存放应用程序，区别是（在目前主流的 64 位操作系统下）前者用于存放 64 位的应用程序，而后者用于存放 32 位的应用程序

- `Windows`文件夹是 Windows 操作系统的核心文件夹，其中比较常用的是`Fonts`文件夹，该文件夹用于存放 Windows 可用的字体，也可以下载第三方字体（一般是`.ttf`文件，双击可安装）

- 用户文件夹（Users）文件夹用于存放所有用户的数据（Windows 支持多用户），每个用户的数据相互独立（用以用户名命名的文件夹区分），其中，可能有的文件夹如下

{% asset_img 用户文件夹.png 图：用户文件夹 %}

- `.config`文件夹
  - 存放一些软件的个人配置文件
- 桌面（Desktop）文件夹
  - 电脑桌面
  - <span style="color:red;font-weight:bold;">即电脑桌面是个特殊的文件夹</span>
- `AppData`文件夹
  - 这是一个隐藏文件夹，需勾选显示隐藏文件夹（后文会介绍）
  - 该文件夹用于存放应用数据或配置文件，其中的`Local`，`Roaming`，`LocalLow`表示不同类型的应用数据

#### 文件系统

<p id="fileSystem"></p>
文件系统是操作系统用于管理文件的“标准”，不同操作系统的文件系统也不同

如今，Windows 主要使用`NTFS`文件系统，不同于老式的`FAT32`操作系统，`NTFS`不再限制单个文件大小为 4GB。且其具有日志功能，可以记录电脑的操作，即使电脑断电，也能更好的恢复电脑数据

**什么时候会用到文件系统？**

文件系统看似与普通用户关系不大，实际上，当我们格式化（清空硬盘数据并改变改变文件系统格式） U 盘或硬盘时，系统会让我们选择一个文件系统。这时如果选择不当，可能会影响硬盘使用体验

**认识文件路径**

为方便管理文件，每个文件夹和文件都有一个自己的“地址”

在 Windows 系统中，路径从盘符开始，基本的路径格式如下

`C:\文件夹1\文件夹2\文件1.txt`

这表明在 C 盘下有一个文件夹叫`文件夹1`，`文件夹1`下有个文件夹叫`文件夹2`，`文件夹2`下有个文件叫`文件 1`

一般的，文件夹（Folder）也被称为<span style="color:red;font-weight:bold;">目录</span>（Directory）

由于文件夹的唯一性，因此在同一目录下，不能存在同名文件或同名文件夹（文件和文件夹也不可以同名）

#### 文件

这里我们需要搞清楚软件和文件的关系

例如一个`.png`图片文件，我们在电脑上直接双击就可以打开了

这看起来很自然，但是实际上，真正的过程是系统调用了相应的软件（如图片查看器），然后软件解析该文件

这时有人可能会问：我电脑上也没装图片查看器啊

其实，大部分 Windows 电脑上都自带了一个叫`照片`的软件（可以在开始菜单搜索搜到），这个软件可以解析`.png`格式的文件

同样的，如果电脑上没装`Microsoft Office`或`WPS Office`等办公软件，我们也无法打开`.docx`，`.pptx`，`.xlsx`等文件，并且这些文件也不会显示相应的图标，这是因为只有在安装相应的软件时，软件会通过修改注册表（后面会有介绍）为这些文件添加图标

对于程序员来说，一个`.c`文件，如果在电脑上没有装编译器或 IDE，那它也就是个普通的文本文件，与`.txt`文件（文本文件）也就只有扩展名不同的区别了

**当电脑上有多个应用可以打开同一个文件时，可以右键该文件，在更多中找到`打开方式`，直接选择相应的应用打开；或者点击`选择其他应用程序`，在弹出的窗口中选择相应的程序后点击始终，从而修改这类文件的默认打开方式**

这里再介绍一种特殊的文件——压缩文件

这类文件通常以`.zip`，`.rar`，`.7z`结尾，不同的扩展名表示不同的压缩算法，微软只为我们提供了处理`.zip`的软件，~~而且确实不太好用~~（可以用第三方软件，后面会介绍）

**压缩文件可以将多个文件夹和文件合并为一个文件，便于传输分享**

综上，**没有软件，那么文件也没有用**

#### 快捷方式

快捷方式可以理解为一个链接，指向相应的文件或网址

通常我们安装软件后出现在桌面的就是快捷方式，其**特点是图标的左下角有一个指向右上的箭头**

因此，**删除快捷方式并不等于卸载软件**，具体的卸载软件的方式后面会介绍

我们也可以创建快捷方式，一般有两种方式

1. 右键相应的文件（软件）或文件夹，在更多中找到并点击创建快捷方式
2. 在空白处右键，点击新建，选择快捷方式，会弹出一个窗口

{% asset_img 快捷方式.png 快捷方式 %}

接着可以在输入框中输入文件（夹）路径或网址

> tips：由于快捷方式只是一个链接，因此，修改快捷方式的文件名或是图标（右键快捷方式，选择更多-属性-快捷方式-更改图标）都不会对原文件（夹）有影响
> 顺带一提，快捷方式其实是有扩展名的，扩展名为 `.ink`

### 系统应用

系统应用分为两种

- 一种是传统的应用程序，一般在 `C:\Windows\System32` 目录下，如任务管理器等

- 另一种是自从 Win10 发布后，微软新推出的应用程序，即 UWP （Universal Windows Platform），这种应用最大的特点是通过微软应用商店（Microsoft Store）下载，存储位置一般在 `C:\Program Files\WindowsApps`，如计算器等

**了解可执行文件**

传统的应用一般是`可执行文件`（以`.exe`结尾）

此外，在网络上可以下载到的可执行文件还有`.msi`（安装包文件，有时候`.exe`文件也可以作为安装包），`.bat/.cmd`（批处理文件，一般用于修改系统设置，文件批量处理）

> 需要注意的是，在 Windows 11 后运行可执行文件时会弹出一个窗口询问是否允许对设备进行修改，因为有的可执行文件可能会携带（或本身就是）病毒等非法程序，<span style="color:red;font-weight:bold;">因此切忌运行来路不明的可执行文件</span>

**动态链接库文件**

我们常常会在应用的安装目录下看到许多`.dll`文件，这些就是动态链接库文件，其包含了一套给可执行程序调用的函数和数据，且可以共享给多个程序调用

可以理解为一个`.dll`文件实现了一个或多个基础功能，可执行程序通过调用这些基础功能从而实现更加复杂的功能

接下来介绍一些比较重要的系统应用

> 注册表（Registry Editor，简写为 `Regedit`）是一个巨大的、分层级的数据库，用于存储 Windows 操作系统、所有硬件设备、以及几乎所有已安装应用程序的配置信息和设置

要想打开注册表，可以直接在开始菜单搜索`注册表`，也可以按下`Win+R`打开**运行窗口**，然后输入`regedit`，并按下回车

### 驱动

前面我们了解到，操作系统是直接和硬件打交道的，但是不同的硬件的制造厂商不同，操作系统如何知道调用这些硬件呢

这就需要驱动程序（Device Driver）了，驱动程序由硬件厂商编写，负责将操作系统的命令翻译成硬件能理解和执行的指令

常见的驱动有**打印机驱动**，**显卡驱动**，**声卡驱动**，**USB 驱动**

因此当你发现某个硬件突然不工作了，除了考虑是否是硬件损坏，应该优先考虑是不是驱动除了问题

也许你会说装电脑这么久从来都没装过驱动，其实是 Windows 系统会自动安装相应的驱动（打印机驱动一般要手动安装），代价是驱动可能不与硬件完全匹配，导致硬件无法发挥最大效能

开始菜单搜索并打开`设备管理器`，可以看到当前计算机的硬件，对于每一个硬件，都能找到对应的驱动程序

当某个硬件图标旁显示了黄色感叹号时，说明该硬件不能正常工作，需要下载相应的驱动

可以选择双击硬件图标，选择`驱动程序-更新驱动程序-自动搜索驱动程序`

{% asset_img 驱动.png 图：下载驱动 %}

如果没有搜索到相应的驱动，则需要去硬件的官网下载相应驱动，然后点击`浏览我的电脑以查找对应驱动`进行手动安装

> tips：安装完驱动后，驱动文件就可以删除了

在了解浏览器之前，我们先来认识一下搜索引擎

#### 搜索引擎

> 搜索引擎（Search Engine）是一种特殊的网站或软件服务。它的核心工作是收集、整理和索引互联网上数以万亿计的网页内容，并在你提出问题时，快速为你找到最相关的信息

搜索引擎利用**爬虫**技术，不断在网络上爬取数据并存入相应的数据库，当用户输入信息时，搜索引擎就会在数据库中检索相关信息，进行排序后展示给用户

目前主流的搜索引擎如下

- **Google**：由谷歌公司开发，是全球最大的搜索引擎，检索能力强，国内网络无法访问
- **Bing**：由微软公司开发，是`Microsoft Edge`浏览器的默认搜索引擎
- **百度**：百度公司开发，国内主流，~~百度广告那么多，不理解为什么要用百度~~

正确使用搜索引擎能帮助我们提高检索信息的效率，以下是一些搜索引擎的“高级”用法

- 精确搜索：`""`
  - 强制搜索引擎只返回完全相同、顺序不变的短语的网页
  - 如搜索 `"苹果手机"`，那么搜索引擎就会返回包含`苹果手机`完整短语的条目
- 排除关键字：`-`
  - 排除不需要的内容
  - 如搜索 `苹果 - 手机`，那么结果中就不会出现苹果手机相关内容，而返回苹果的相关条目
- 站内搜索：`site:`
  - 在特定网站搜索
  - 如搜索 `二分查找 site:www.zhihu.com`，那么结果全是知乎中关于二分查找的文章
- 按文件类型查找：`filetype:`
  - 查找文件
  - 如搜索 `数据结构 filetype:pdf` 那么返回的结果就都是 pdf 文件

#### 环境变量

环境变量相当于计算机全局的变量，通过设置环境变量，我们可以在计算机的其他地方访问到某个特定文件或文件夹

通过`Win+R`呼出运行窗口，输入`taskmgr`会发现系统打开了任务管理器

实际上，任务管理器作为一个软件（文件名为`taskmgr.exe`），其保存在文件夹`C:\Windows\System32`中，Windows 系统通过设置该目录为环境变量，将该目录下中所有的文件添加到了环境变量中，使得这些文件可以在全局被访问（如果是`.exe`文件，在访问时可以省略扩展名）

同样的，如果在运行窗口或资源管理器的路径栏中输入`%windir%`，资源管理器就会自动跳转到`C:\Windows`路径下，因为 Windows 默认将 `windir` 作为该路径的变量名，通过 `%变量名%` 就可以直接访问该路径

#### 配置环境变量

在桌面上右键此电脑（没有的需按前文个性化设置条目进行配置），点击属性，往下翻可以找到`高级系统设置`，然后点击`环境变量`

{% asset_img 环境变量.png 图：环境变量 %}

在弹出的窗口中可以看到两栏，**用户变量**和**系统变量**

> Windows 是一个多用户系统，即一个电脑可以有多个用户
> 不同用户有不同的电脑桌面，文件等，权限也可以不同

我们一般不需要对此进行区分，只需要操作**用户变量**就行

首先需要关注`Path`变量，双击该变量，在弹出的窗口中我们可以看到很多路径，这里存放的就是文件（软件）的环境变量（注意是添加该文件所在的目录）

比如在`C:\Program Files (x86)\mingw64\bin`目录下有一个`gcc.exe`文件，我想把该文件添加到环境变量，只需要点开`Path`，然后点击新建，复制该路径就可以了
